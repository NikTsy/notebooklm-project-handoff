# NotebookLM Project Handoff

This repository ships a Codex skill for other projects. For installation, follow the Quick start in README.md. Apply examples/AGENTS.md and examples/PROJECT_CONTEXT.md in the target project, merging with its existing files.

- Installable skill and runtime scripts: .agents/skills/notebooklm-project-handoff/
- Backend setup: docs/notebooklm-setup.md
- Benchmark methodology and results: docs/benchmarks.md

For changes here, keep the README examples aligned with the scripts. Exercise local lookup with the example summary and use an isolated project with a test backend for publisher checks. The target project's .notebooklm-handoff/ directory contains local configuration and publication state.
